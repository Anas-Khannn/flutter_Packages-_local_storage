| Storage Type | Suitable Example | Unsuitable Example |
|---|---|---|
| Shared Preferences | Theme or language selection | Password or access token |
| Secure Storage | Private note or access token | Large searchable collection of records |
| Local Database | Offline inventory with relational queries | Shared live data across devices without synchronization |
| Cloud/Backend | Multi-user synchronized orders | A device-only theme setting requiring no network |

Security rule: use secure storage for passwords, access tokens, and other sensitive values.
